# Favour Emmanuel - Portfolio

- Responsive design
- SPA-style navigation
- Project showcase with detail pages
- Animated skills ticker

## Tech Stack

Python, Django, Flask, FastAPI, PostgreSQL, React, TypeScript, and more.
